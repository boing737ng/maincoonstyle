# Maincoon Style

Сайт-витрина питомника мейн-кунов с админ-панелью для самостоятельного управления каталогом животных.

## Стек

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS 4** (тёмная тема, светлый текст)
- **PostgreSQL** + **Prisma 6**
- **MinIO** (S3-совместимое хранилище фотографий)
- **JWT-сессии** (`jose`) для авторизации одного администратора

## Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Настроить окружение
cp .env.example .env   # затем заполнить реальными значениями

# 3. Поднять базу данных и MinIO (Docker)
docker compose up -d

# 4. Применить миграции
npm run db:migrate

# 5. Создать учётную запись администратора
npm run db:seed

# 6. Запустить сайт
npm run dev
```

Сайт: <http://localhost:3000>
Админ-панель: <http://localhost:3000/admin>

## Переменные окружения

См. `.env.example`. Ключевые:

- `DATABASE_URL` — строка подключения PostgreSQL (порт 54321 для Docker).
- `AUTH_SECRET` — секрет для подписи сессий.
- `ADMIN_LOGIN` / `ADMIN_PASSWORD` — учётные данные администратора (используются только при `db:seed`).
- `S3_*` — параметры подключения к MinIO.

> **Важно:** на этой машине запущены системные службы PostgreSQL (порты 5432 и 5433).
> Поэтому Docker-контейнер с базой данных привязан к порту **54321**.

## Структура

```
src/
  app/
    (site)/        # публичный лендинг
    admin/         # админ-панель
    api/           # маршруты API
  components/      # переиспользуемые компоненты
  lib/             # слой данных, схемы, утилиты
prisma/
  schema.prisma
  migrations/
  seed.ts
```

## Модель данных

- `Animal` — животное (котёнок / кот / кошка) с полями: номер, кличка, дата рождения, пол, окрас, цена, родители, характер, статус, публикация, порядок.
- `AnimalPhoto` — до 5 фотографий на животное, с обложкой и порядком.
- `AdminUser` — единственный администратор.
